# Dữ liệu danh mục

Kèm danh mục công khai đã được crawler lưu, phục vụ unit test và seed môi trường mới; không kèm dữ liệu khách hàng hoặc bản sao database. Dữ liệu nằm trong repo backend để seed chạy được cả local lẫn trong image; crawler ở repo storefront (`tools/scrapers/crawl-cwwines.js`) ghi thẳng vào thư mục này. Ảnh giao diện và nội dung tĩnh đang dùng đã nằm trong storefront. Kiểm tra quyền sử dụng nội dung trước khi phát hành tên miền mới.
